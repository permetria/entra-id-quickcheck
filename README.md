# entra-id-quickcheck
Co skript dělá: jen čte a projde 6 základních kontrol: počet globálních adminů, vynucení MFA, blokování legacy autentizace, souhlas uživatelů s aplikacemi, registraci aplikací a zvaní hostů. Stačí mu jeden lehký modul Microsoft.Graph.Authentication. Výstup je česky, barevně a jde uložit do CSV.
